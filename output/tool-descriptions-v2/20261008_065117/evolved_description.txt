Searches local file contents by substring or regular expression across the entire working tree using a fast Ripgrep-based engine. It returns matching lines with line numbers, file paths, or counts when targeting file contents. It can also locate files by name using glob patterns without reading their contents. Automatically excludes macOS TCC-protected folders when searching above the user home directory unless explicitly included. Use this tool exclusively for searching local files by content or filename. It does not perform web searches, fetch web pages, run commands, execute code, or edit files.
